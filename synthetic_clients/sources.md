# Этап 1. Источники и целевые распределения

Статус: **версия 3** (11.11.2026).
- Решения заказчика по противоречиям внесены (раздел 3).
- Убраны 6 полей: отрасль, стаж клиента, «основной банк», CES, стиль общения (перенесён в качественный слой как черта персоны) и готовность ждать оператора (объединена с отношением к чат-боту).
- Проведён дополнительный поиск источников (раздел 6).
- Для слоя «Поддержка» составлен список экспертных данных, которые соберёт заказчик (раздел 4б).

Обозначения в колонке «Тип»:
- **[источник]** — цифра взята из первоисточника, я его открыл и проверил сам;
- **[производное]** — посчитано из цифр источника (формула указана);
- **[прокси]** — источник есть, но описывает смежную величину;
- **[не сверено]** — цифра из вторичного пересказа (СМИ), первоисточник открыть не удалось;
- **[допущение]** — открытой статистики нет, значение предлагаю я (раздел 4);
- **[эксперт]** — будущая экспертная оценка заказчика: агрегированная, без внутренних данных банка (раздел 4б).

> **Ограничение доступа.** Сайт Росстата из рабочей среды недоступен: его сертификат выдан российским удостоверяющим центром, которого нет в стандартном наборе. Данные Росстата взяты из публикаций Банка России, Демоскопа (ВШЭ) и Социального фонда со ссылкой на Росстат. Половозрастная сетка — оценка ООН (WPP 2024), см. раздел 3.

## 3. Противоречия источников — решения заказчика (11.11.2026)

1. **Доля 60+ среди взрослых** (слайд ЦБ — 35%, ООН — 30,4%). **Решение:** для первых прогонов берём ООН; пересмотреть, когда появятся таблицы Росстата.
2. **Мобильный банк по возрасту.** **Решение:** общий уровень — НАФИ (74%), градиент — допущение Д27; пересмотреть при появлении данных.
3. **Категории населённого пункта.** **Решение:** категории источника (Москва / СПб / 500 тыс.+ / до 500 тыс. / село).
4. *(новое, решения не требует)* **Кредитная карта: 39% или 24%?** Это разные определения. 39% — «есть карта» (опрос ЦБ [19]), 24% — «пользуется с долгом» (БКИ [8]). В базе поле «есть кредитная карта» = 39%. Признак «есть долг по карте» можно добавить позже на основе 24%.
