# Этап 1. Источники и целевые распределения

Статус: **версия 2** (11.11.2026). Решения заказчика по противоречиям внесены (раздел 3); вопрос о пороге допущений открыт (раздел 4а).

Обозначения в колонке «Тип»:
- **[источник]** — цифра взята из первоисточника, я его открыл и проверил сам;
- **[производное]** — посчитано из цифр источника (формула указана);
- **[прокси]** — источник есть, но описывает смежную величину (например, жалобы в ЦБ вместо обращений в поддержку);
- **[не сверено]** — цифра из вторичного пересказа (СМИ), первоисточник открыть не удалось;
- **[допущение]** — открытой статистики нет, значение предлагаю я; все допущения собраны в разделе 4.

> **Ограничение доступа.** Сайт Росстата (rosstat.gov.ru, fedstat.ru) из рабочей среды недоступен: его сертификат выдан российским удостоверяющим центром, которого нет в стандартном наборе. Поэтому данные Росстата взяты из публикаций, где их приводят Банк России, Демоскоп/ВШЭ и СФР со ссылкой на Росстат. Половозрастная сетка взята из оценки ООН (WPP 2024) — решение заказчика, см. раздел 3.

## 3. Противоречия источников — решения заказчика (11.11.2026)

1. **Доля 60+ среди взрослых** (слайд ЦБ «Росстат» — 35%, ООН — 30,4%). **Решение:** для первых прогонов берём оценку ООН. Пересмотреть, когда появятся таблицы Росстата.
2. **Мобильный банк по возрасту** (у НАФИ «45+» пользуются больше молодых; у Mediascope цифровая активность падает после 55). **Решение:** общий уровень — НАФИ (74%), возрастной градиент — допущение Д27 с разбросом внутри групп. Пересмотреть при появлении точных данных.
3. **Категории населённого пункта.** **Решение:** категории источника — Москва / Санкт-Петербург / 500 тыс.+ / до 500 тыс. / село.
